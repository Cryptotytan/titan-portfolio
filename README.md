# Titan

Cosmic portfolio for **Titan** — community, on-chain dashboards, partnerships, and AI video.

Live site: built with TanStack Start, Tailwind, and Three.js.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (default `http://localhost:8080`).

```bash
npm run build
npm run preview
```

## Stack

- TanStack Start + React
- Tailwind v4
- Three.js solar system
- Hover-play AI video cards
